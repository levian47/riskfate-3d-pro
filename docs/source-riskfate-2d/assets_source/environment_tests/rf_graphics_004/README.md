# RF-GRAPHICS-004 — матеріали для подальшої інтеграції

Збережено за прямим дорученням власника від 05.11.2026. Це збереження напрацювань, а не підтвердження їхньої готовності в Godot.

## Що використовувати

- [Підготовлені об’єкти](../../../world/environment/settlement_v1/) — дерево, криниця, горизонтальна й вертикальна секції та кут огорожі. Статус **Тестується**.
- [Тайли](../../../world/tilesets/settlement_v1/) — трава/ґрунт 32×32, атлас 47 переходів і terrain_layout.json. Статус **Тестується**; Godot TileSet ще не налаштовано.
- [Схвалений будинок](../../environment_concepts/riskfate_house_approved_reference_v1.png) — єдиний актуальний художній варіант будинку. Оригінал 1254×1254 збережено раніше без змін. **Його похідний ігровий спрайт ще не підготовлено.**
- [sources/](sources/) — незмінені вихідні генерації дерева, криниці, огорожі та землі для можливого доопрацювання.

## Історичні матеріали

Відхилені окремі файли будинків і вихідні генерації видалено з репозиторію за дорученням власника 05.11.2026. Контрольні зображення та HTML-переглядач — історичні кадри; вони досі показують тестову композицію з відхиленим будинком v1, тому не є чинним еталоном і не призначені для інтеграції.

[review/](review/) — контрольні композиції 1×/Nearest ×2, аркуш ресурсів, тестові колізії, приклад перекриття кроною та автономний HTML-переглядач. У цих композиціях **старий відхилений будинок v1**. Це історичний тест масштабу, а не поточна затверджена сцена.

[historical_report.md](historical_report.md) та [historical_verification.json](historical_verification.json) фіксують попередні числові перевірки: RGBA, альфа 0/255, палітра, Nearest ×2, незмінений герой, 22 800 стиків тайлів із покриттям 47 конфігурацій. Ці перевірки не підтверджують художньої якості всього набору. Геометричні дефекти старого будинку були виявлені пізніше власником.

## Перед інтеграцією

1. Підготувати і перевірити ігровий будинок саме зі схваленого оригіналу, зберігши його вигляд. Не зменшувати й не підміняти оригінал автоматично під час завантаження.
2. Перевірити **цілісно кожен об’єкт** за GRAPHICS_GUIDELINES.md: обводку, геометрію всіх частин, палітру, масштаб поруч із героєм.
3. [metadata.json](metadata.json) містить тестові опори й полігони колізій. Їх не затверджено; не переносити на новий будинок автоматично. Усі координати задано від верхнього лівого кута відповідного PNG; кінці полігонів можуть лежати на межі полотна.
4. У Godot налаштувати Nearest, імпорт, TileSet, опори, колізії та порядок перекриття в межах окремого завдання. Зникнення героя за кроною не вирішено статичними PNG.
5. Провести перевірки Godot/Web і окреме візуальне приймання на фізичному смартфоні. Їх ще не виконано.

Код, сцени, CI та налаштування Godot під час цього збереження не змінювалися. Герой уже є у репозиторії й повторно не копіюється. [asset_manifest.json](asset_manifest.json) містить точні шляхи, SHA-256 та Git blob SHA збережених матеріалів.
