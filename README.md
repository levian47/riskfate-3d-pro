# Riskfate 3D Pro

**Riskfate 3D Pro** — окремий експериментальний проєкт стилізованої low-poly/процедурної 3D-гри на **Godot 4.7.2**, орієнтований на поступове створення функціональної фентезійної MMORPG. Пріоритети — керований персонаж, зрозумілі механіки, мобільне керування, продуктивність і подальша серверна архітектура.

## Поточний стан

**У `main` наявний Godot-проєкт з ігровою сценою, GDScript-керуванням, сенсорним UI та моделлю Ninja.** Додано окремий компонент `world/environment.gd` із територією 220×220 умовних одиниць, низькополігональними деревами, кущами, камінням, руїнами й табором. Біг і стрибок тепер можуть анімуватися одночасно з прискореною атакою через верхній шар `AnimationTree`. Перевірка у реальному браузері та на телефоні є окремим етапом. Налаштовано автоматичний Web-експорт і GitHub Pages. Сама наявність workflow не є підтвердженням успішного Web-запуску або тестування на телефоні.

## Локальний запуск

Відкрий кореневий `project.godot` у **Godot 4.7.2 Stable** і запусти основну сцену. Для ручного Web-експорту потрібні шаблони експорту відповідної версії та preset `Web`. Результат збірки створюється в `dist/` і не є частиною вихідних файлів проєкту.
