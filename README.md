# Riskfate 3D Pro

**Riskfate 3D Pro** — окремий експериментальний проєкт стилізованої low-poly/процедурної 3D-гри на **Godot 4.7.2**, орієнтований на поступове створення функціональної фентезійної MMORPG. Пріоритети — керований персонаж, зрозумілі механіки, мобільне керування, продуктивність і подальша серверна архітектура.

## Поточний стан

**У `main` наявний Godot-проєкт з ігровою сценою, GDScript-керуванням, сенсорним UI та моделлю Ninja.** Додано окремий компонент `world/environment.gd` із територією 220×220 умовних одиниць, низькополігональними деревами, кущами, камінням, руїнами й табором. Біг і стрибок тепер можуть анімуватися одночасно з прискореною атакою через верхній шар `AnimationTree`. Налаштовано автоматичний Web-експорт і GitHub Pages. Остання перевірена CI-збірка включає пряме керування без інерції, ривок і мобільні кнопки. Власник протестував Web-версію та схвалив поточне відчуття керування як базову основу. Це не означає повного тестування кожної ігрової механіки, браузера чи моделі телефона.

Напрямок руху та поворот відповідають джойстику без інерції: при відпусканні рух зупиняється. **JUMP** розміщено внизу праворуч, **DASH** — на попередньому місці стрибка; ривок короткий, з тестовою перезарядкою. На ПК ривок — клавіша **Q**. Кругла кнопка **FULL** у верхньому лівому куті (видима також у вертикальній орієнтації) вмикає/вимикає повноекранний режим. На ПК доступна кнопка **FULLSCREEN** у правому верхньому куті. Браузер може заборонити цей режим або показати власне підтвердження; на мобільному пристрої результат потребує перевірки. Поточна реакція керування схвалена власником; сумісність з іншими телефонами, орієнтаціями та браузерами потребує додаткових тестів.

## Прийнятий базовий варіант керування (06.11.2026)

Власник позитивно оцінив поточний рух у Web-версії та попросив зафіксувати його як основу подальшої роботи. **Зберігати при наступних змінах:**

- Рух відносно камери точно за напрямком лівого аналогового джойстика, без згладжування прискорення, гальмування чи повороту. Різка зміна напрямку та відпускання мають відпрацьовувати без затримки, також у повітрі.
- На смартфоні (горизонтальна орієнтація): джойстик ліворуч; праворуч велика кнопка **ATK**, **JUMP** нижче, **DASH** на попередньому місці стрибка; **ZOOM** із трьома фіксованими рівнями та **FULL** угорі.
- Атака верхньою частиною тіла не повинна переривати рух ніг, стрибок або керування; ривок виконується окремою командою та не змінює постійно базову швидкість пересування.
- На ПК: **WASD** — рух, **Shift** — біг, **Space** — стрибок, **Q** — ривок, ліва кнопка миші — атака.

**Не зафіксовано як остаточний баланс:** швидкості ходьби/бігу, швидкість ривка `24`, його тривалість `0.18 с`, перезарядка `0.85 с`, швидкість атаки ×`1.65`, числовий кут та масштаб камери. Це чинні параметри реалізації, які можна змінювати за подальшим рішенням власника.

## Локальний запуск

Відкрий кореневий `project.godot` у **Godot 4.7.2 Stable** і запусти основну сцену. Для ручного Web-експорту потрібні шаблони експорту відповідної версії та preset `Web`. Результат збірки створюється в `dist/` і не є частиною вихідних файлів проєкту.
