# Riskfate 3D Pro

**Riskfate 3D Pro** — окремий експериментальний проєкт стилізованої low-poly/процедурної 3D-гри на **Godot 4.7.2**, орієнтований на поступове створення функціональної фентезійної MMORPG. Пріоритети — керований персонаж, зрозумілі механіки, мобільне керування, продуктивність і подальша серверна архітектура.

## Поточний стан

**У `main` наявний Godot-проєкт з ігровою сценою, GDScript-керуванням, сенсорним UI та моделлю Ninja.** Налаштовано автоматичний Web-експорт і GitHub Pages. Сама наявність workflow не є підтвердженням успішного Web-запуску або тестування на телефоні.

## Запуск через браузер

**Адреса публікації (після успішного розгортання GitHub Pages):**
https://levian47.github.io/riskfate-3d-pro/

Якщо за адресою 404 або сторінка не запускається, перевір [GitHub Actions](https://github.com/levian47/riskfate-3d-pro/actions/workflows/godot-web.yml) та в `Settings → Pages` вибери `Build and deployment → Source: GitHub Actions`. **Поки немає успішного деплою, це очікувана URL-адреса, а не перевірене робоче посилання.**

На смартфоні відкрий посилання в сучасному браузері та поверни пристрій горизонтально; перевір сенсорний джойстик, атаку, стрибок і масштаб камери. Фізичний телефон потребує окремого підтвердження власником.

## Локальний запуск

Відкрий кореневий `project.godot` у **Godot 4.7.2 Stable** і запусти основну сцену. Для ручного Web-експорту потрібні шаблони експорту відповідної версії та preset `Web`. Результат збірки створюється в `dist/` і не є частиною вихідних файлів проєкту.

## Головні принципи

- Погоджені в концепції механіки успадковано як основу 3D Pro; невизначені значення не стають затвердженими.
- Не переносити технічну реалізацію, візуальні стандарти або статуси тестів іншої гри.
- Розробляти невеликими перевіреними частинами; для Web і смартфона фактична працездатність має бути підтверджена окремо.
- Офіційне джерело правди для цього проєкту: https://github.com/levian47/riskfate-3d-pro, гілка `main`.
