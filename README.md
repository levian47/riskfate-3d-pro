# Riskfate 3D Pro

**Riskfate 3D Pro** — окремий експериментальний проєкт стилізованої low-poly/процедурної 3D-гри на **Godot 4.7.2**, орієнтований на поступове створення функціональної фентезійної MMORPG. Пріоритети — керований персонаж, зрозумілі механіки, мобільне керування, продуктивність і подальша серверна архітектура.

## Поточний стан

**У `main` наявний Godot-проєкт з ігровою сценою, GDScript-керуванням, сенсорним UI та моделлю Ninja.** Налаштовано автоматичний Web-експорт і GitHub Pages. Сама наявність workflow не є підтвердженням успішного Web-запуску або тестування на телефоні.

## Запуск через браузер

**Адреса публікації (зараз недоступна — GitHub Pages потрібно увімкнути):**
https://levian47.github.io/riskfate-3d-pro/

**Перевірено 06.11.2026:** [збірка GitHub Actions №42287805210](https://github.com/levian47/riskfate-3d-pro/actions/runs/42287805210) успішно імпортувала проєкт, експортувала Web-файли та завантажила артефакт. Етап `Deploy to GitHub Pages` завершився **помилкою 404**: Pages ще не ввімкнено для цього репозиторію. Для завершення відкрий [Settings → Pages](https://github.com/levian47/riskfate-3d-pro/settings/pages), вибери **Build and deployment → Source: GitHub Actions**, збережи налаштування та повтори невдале розгортання в Actions (або запусти workflow вручну). **Посилання не підтверджене як робоче до успішного розгортання та браузерної перевірки.**

На смартфоні відкрий посилання в сучасному браузері та поверни пристрій горизонтально; перевір сенсорний джойстик, атаку, стрибок і масштаб камери. Кругла кнопка **FULL** у верхньому лівому куті (видима також у вертикальній орієнтації) вмикає/вимикає повноекранний режим. На ПК доступна кнопка **FULLSCREEN** у правому верхньому куті. Браузер може заборонити цей режим або показати власне підтвердження; на мобільному пристрої результат потребує перевірки. Фізичний телефон потребує окремого підтвердження власником.

## Локальний запуск

Відкрий кореневий `project.godot` у **Godot 4.7.2 Stable** і запусти основну сцену. Для ручного Web-експорту потрібні шаблони експорту відповідної версії та preset `Web`. Результат збірки створюється в `dist/` і не є частиною вихідних файлів проєкту.

## Головні принципи

- Погоджені в концепції механіки успадковано як основу 3D Pro; невизначені значення не стають затвердженими.
- Не переносити технічну реалізацію, візуальні стандарти або статуси тестів іншої гри.
- Розробляти невеликими перевіреними частинами; для Web і смартфона фактична працездатність має бути підтверджена окремо.
